How to Get This App Online & Send It to Citizens

Follow these 3 simple methods to share your live website with anyone in the world for free.

Option A: Host Free on Netlify (1-Minute Direct Upload)

1. Save this file to your computer as index.html.
2. Go to app.netlify.com/drop.
3. Drag & drop the index.html file.
4. Netlify will give you a live website link (e.g., https://yourname-civic.netlify.app) that you can send to any citizen!

Option B: Free GitHub Pages

1. Create a free account on GitHub.com.
2. Create a repository named civic-platform.
3. Upload index.html and enable GitHub Pages in settings.
4. Your live link will be https://username.github.io/civic-platform.
